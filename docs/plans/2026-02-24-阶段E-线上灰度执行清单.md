# 阶段E线上灰度执行清单（可直接执行）

## 1. 目标

- 将 Stage E 人工验收从“本地预演通过”推进到“线上灰度完成并可审计”。
- 所有关键步骤保留可追溯产物（json/md）。

## 2. 预检查

- [ ] 确认线上后端地址（示例：`http://<prod-host>:8001`）。
- [ ] 确认 `DATA_DIR`、日志目录、告警接收人配置已生效。
- [ ] 确认当前发布版本号与回滚版本号已冻结。

## 3. 一键人工验收（线上环境）

执行命令：

```bash
python scripts/stage_e/run_stage_e_manual_acceptance.py \
  --base-url http://<prod-host>:8001 \
  --output-dir data/research/stage_e/manual_prod_YYYYMMDD \
  --dataset-ids research_boreholes_28 research_boreholes_36 \
  --auto-register \
  --label-column label
```

验收通过标准：

- `manual_acceptance_report.json` 中 `all_passed=true`
- `perf_http/evaluation.json` 中 `all_passed=true`
- `research/template_e2e_manual.json` 中 `all_passed=true`

## 4. 灰度发布（10% -> 30% -> 100%）

### 4.1 灰度 10%

- [ ] 开启 10% 流量，观察 30 分钟。
- [ ] 记录成功率、P95/P99、Geomodel 队列长度。
- [ ] 若异常，立即执行回滚步骤（见第 6 节）。

### 4.2 灰度 30%

- [ ] 开启 30% 流量，观察 30 分钟。
- [ ] 核对 fallback 比例是否异常升高。
- [ ] 核对报告导出成功率。

### 4.3 全量 100%

- [ ] 切换到 100% 流量。
- [ ] 持续监控 60 分钟，确认无 P0/P1 问题。

## 5. 告警与值班联动演练

- [ ] 人工触发一条演练告警（不影响业务）。
- [ ] 确认通知链路到达值班群/值班人。
- [ ] 记录告警触发时间、确认时间、恢复时间。

## 6. 回滚触发演练

触发条件示例（满足任一）：

- [ ] 核心接口成功率持续低于 99%
- [ ] P95 持续超阈值 15 分钟且无恢复趋势
- [ ] Geomodel 队列积压失控

回滚动作：

- [ ] 关闭 geology-aware 开关（回退 baseline）
- [ ] 回滚至上一个稳定版本
- [ ] 重跑最小回归链路（Interpolation/MpiHeatmapPro/Report/GeoMpiStudio）

## 7. 发布后 24h 观察

- [ ] 每 2 小时记录一次核心指标快照
- [ ] 记录异常事件与恢复动作
- [ ] 形成 24h 观察报告并归档到 `docs/plans/`
